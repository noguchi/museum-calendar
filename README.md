# Museum Calendar for WordPress

GoogleカレンダーなどのICS URLから予定を取得し、月間カレンダーと本日の予定をWordPressのページに表示するプラグインです。
APIキーやGoogleへのログインは不要です。管理画面での名前は **Museum Calendar** です。

## 必要なもの

- WordPress 7.1.4以上
- PHP 8.5.12以上
- MariaDB 10.11.18以上
- 表示したいカレンダーのICS URL（HTTPS）

## 導入

1. プラグインのZIPファイルを用意します。ZIPの作り方は[開発の手引き](docs/development.md)にあります。
2. WordPressの「プラグイン → プラグインを追加 → プラグインのアップロード」でZIPを選び、インストールします。
3. 「Museum Calendar for WordPress」を有効化します。

## ICS URLの登録

1. Googleカレンダーの「設定 → カレンダーの統合」でiCal形式のURLをコピーします。
2. WordPressの「設定 → Museum Calendar」にURLを貼り付け、「設定を保存」を押します。
3. 「今すぐ更新」を押し、最終成功日時が表示されることを確認します。

「iCal形式の公開URL」を使う場合は、カレンダーを一般公開に設定してください。
「iCal形式の非公開URL」は、知っている人なら誰でも予定を読めるURLです。公開ページやメールに書かないでください。
保存したURLは設定画面に再表示しません。空欄のまま保存すると登録済みのURLを維持します。「接続を解除し、保存済みの予定を消去する」にチェックを入れて保存すると消去します。
URLはWordPressのDBに保存されるため、DBのバックアップも同じように保管してください。

## ページへの表示

表示したい固定ページや投稿に、次のショートコードを書きます。

| ショートコード | 表示内容 |
| --- | --- |
| `[museum_calendar]` | 当月の月間カレンダー。前月と翌月へ移動できます。 |
| `[museum_calendar month="2026-11"]` | 指定した月だけの月間カレンダー。 |
| `[museum_calendar_today]` | 本日の日付と当日の予定。 |

表示するのは予定のタイトルと時間だけで、日時は日本時間です。予定の説明や参加者は表示しません。
月間カレンダーの週は、WordPressの「設定 → 一般 → 週の始まり」で選んだ曜日から始まります。日曜始まりにするには、そこで「日曜日」を選んで保存します。
本日の日付の表記は、WordPressの「設定 → 一般 → 日付形式」で選びます。「カスタム」に `n月j日(D)` と入力して保存すると、`11月16日(月)` のように曜日も表示します。
月間カレンダーは1ページに1つだけ置いてください。

## 見た目の変更

テーマから、色と寸法（CSS変数）、表示する予定（フィルター）、HTML（テンプレートの差し替え）を変更できます。
プラグインのファイルは更新で上書きされるため、直接編集しないでください。
方法は[仕様の「カスタマイズ」](docs/specification.md#カスタマイズ)にあります。

## 予定の更新

- 予定は約15分ごとに取り直します。Googleカレンダーの変更がすぐに反映されるとは限りません。
- すぐに反映したいときは、「設定 → Museum Calendar」の「今すぐ更新」を押します。
- 取得に失敗した場合は、前回取得した予定を最長24時間表示し、最終取得日時を案内します。24時間を過ぎると、予定を取得できない旨を表示します。
- ページキャッシュのプラグインやサービスを使っている場合、本日の予定が前日の内容のまま残ることがあります。予定を置いたページのキャッシュ時間を短くしてください。
