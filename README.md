# Museum Calendar for WordPress

Googleカレンダーの予定を、月間カレンダーと本日の予定としてWordPressのページに表示するプラグインです。

サンプル: https://collaborative-macaw-b043ed.instawp.site

## 必要なもの

- WordPress 7.1.4以上、PHP 8.5.12以上、MariaDB 10.11.18以上
- サイトに載せる予定だけを入れた、専用のGoogleカレンダー。一般公開は不要で、職員のアカウントと共有して使います

> [!IMPORTANT]
> カレンダー自体は非公開でも、登録したカレンダーの予定は、説明欄を含めてすべてサイトで公開されます。
> 内部の予定を入れたカレンダーは登録せず、サイト用の専用のカレンダーを使ってください。

## インストール

1. [Releases](https://github.com/noguchi/museum-calendar/releases)から `museum-calendar-<VERSION>.zip` をダウンロードします。
2. WordPressの「プラグイン → プラグインを追加 → プラグインのアップロード」でZIPをインストールし、有効化します。
3. Googleカレンダーで、画面左側の「他のカレンダー＋　→　新しいカレンダーを作成」からサイト用のカレンダーを作ります。
4. 「設定と共有」の「予定のアクセス権限」で「一般公開して誰でも利用できるようにする」はオフのままにします。
5. 同じ画面の「特定のユーザーまたはグループと共有する」で、予定を登録する職員のアカウントまたはグループを追加します。
6. 同じ画面の「カレンダーの統合」にある「iCal形式の非公開URL」をコピーします。
7. WordPressの「設定 → Museum Calendar」の「iCal形式の非公開URL」に貼り付け、「設定を保存」を押します。保存と同時に予定を取得します。

- 保存したURLは画面に再表示しません。登録済みかどうかは、入力欄の上の「登録状況」に出ます。
- 接続を解除するには「接続を解除する」をチェックして保存します。取得済みの予定も消えます。
- 一般公開したカレンダーの「iCal形式の公開URL」も登録できます。

### 非公開URLの扱い

「iCal形式の非公開URL」はパスワードと同じです。URLを知っている人は、誰でもカレンダーのすべての予定を読めます。

- メールやチャットに貼らず、WordPressの入力欄にだけ貼り付けます。
- 漏れたときは、Googleカレンダーの「設定と共有 → カレンダーの統合」で「iCal形式の非公開URL」の横の「リセット」を押し、新しいURLを登録し直します。
- URLはWordPressのデータベースに保存されます。データベースのバックアップもパスワードと同じように扱います。
- プラグインを削除すると、保存したURLと設定はデータベースから消えます。無効化しただけでは残ります。

## ページに表示する

固定ページや投稿にショートコードを書きます。

| ショートコード | 表示内容 |
| --- | --- |
| `[museum_calendar]` | 当月の月間カレンダー。前月と翌月へ移動できます。先へ進めるのは翌々月までです |
| `[museum_calendar_today]` | 本日の日付、開館状況、当日の予定 |

- 月間カレンダーは1ページに1つだけ置けます。
- 英語のページでは `[museum_calendar lang="en"]` のように `lang="en"` を付けます。見出しと案内が英語になり、予定名は設定画面に登録した英訳になります。
- 日時は日本時間です。週の始まり、月と曜日の言語、本日の日付の表記は、WordPressの「設定 → 一般」に従います。

## デザインをサイトに合わせる

色、寸法、HTMLの変更は、テーマのCSS、追加CSS、テーマのテンプレートで行います。
プラグインのファイルは更新で上書きされるので、編集しないでください。

### サンプルのCSSから始める

プラグインの `samples/` フォルダーに、デザインのサンプルが3つあります。

| ファイル | 内容 |
| --- | --- |
| `default.css` | プラグインの既定の見た目。CSS変数を既定値のまま並べたもので、値を書き換えて使います |
| `monochrome.css` | 黒地に細い罫線。予定の種類を濃淡と枠線で区別します |
| `pop.css` | 明るい色と太い枠。曜日と予定の種類ごとに色を変えます |

使うファイルの中身を、テーマのCSSか「外観 → カスタマイズ → 追加CSS」に貼り付けます。
サンプルはプラグインのテンプレートに合わせてあるので、下の「HTMLを変える」でテンプレートを差し替えたサイトには合いません。

### 色と寸法を変える

テーマのCSSでCSS変数を宣言します。

```css
:root {
  --museum-calendar-text: #222;
  --museum-calendar-accent: #7a5c2e;
  --museum-calendar-max-width: 1080px;
}
```

変数の一覧と既定値は[仕様の「CSS変数」](docs/specification.md#css変数)にあります。

### 予定の種類ごとに色を付ける

プラグインは、予定のタイトルから種類を決めて `data-kind` に出力します。
タイトル、種類、英語での表示、色の対応は、「設定 → Museum Calendar」の「予定の種類と英語での表示」の表で編集します。
次の8行は既定の表です。

| カレンダーに登録したタイトル | `data-kind` | 英語のページでの表示 | 色 |
| --- | --- | --- | --- |
| `開館日` | `open` | `OPEN` | `#ffebee` |
| `休館日` | `closed` | `CLOSED` | `#f5f5f5` |
| `お茶室営業日` | `tea` | `Tea Room Open` | `#e8f5e9` |
| `ガイドツアー開催日` | `tour` | `Guided Tour` | `#e3f2fd` |
| `結婚式` | `wedding` | `Wedding` | `#fff0fc` |
| `夜間特別開館` | `evening` | `Special Evening Opening` | `#fff9f4` |
| `コンサート` | `concert` | `Concert` | `#f5f5f5` |
| `イベント` | `event` | `Event` | `#f5f5f5` |

- タイトルは全体が一致したときだけその行の種類になります。前後の空白は無視し、大文字と小文字は区別します。
- 表にないタイトルの種類は `other` で、色は付きません。該当するタイトルは同じ画面の「種類が未定義の予定名」に並びます（今月から12か月分）。
- 行を追加するには、表の下の空欄の行に入力して保存します。行を消すには、タイトルを空欄にして保存します。
- 種類は、英小文字で始まる英小文字、数字、ハイフンで書きます（例: `workshop`）。複数のタイトルに同じ種類を付けられます。`other` は使えません。
- `open` と `closed` は本日の開館状況に使います。`closed` の予定がある日は、その日の `open` の予定を表示しません。
- 英語での表示が空欄の行と表にないタイトルは、英語のページでも登録したタイトルのまま表示します。
- 色は月間カレンダーの予定と本日の開館状況の背景色で、`#` に続く6桁の16進数で書きます（例: `#e3f2fd`）。空欄なら色を付けません。左線と文字色は、背景色からプラグインが計算します。
- 「既定の表に戻す」をチェックして保存すると、上の8行に戻ります。

テーマのCSSで指定した色は、表の色より優先します。

```css
.museum-calendar li[data-kind="tour"] { --museum-calendar-event-accent: #2f6f4f; }
.museum-calendar-today__status[data-kind="closed"] { background: #f3dede; }
```

### HTMLを変える

テーマにテンプレートを置くと、プラグインのテンプレートの代わりに使われます。

1. プラグインの `templates/month.php`（月間カレンダー）または `templates/today.php`（本日の予定）を、テーマの `museum-calendar/` フォルダーにコピーします。
2. コピーしたファイルを編集します。

- テンプレートに渡る値はエスケープされていません。`esc_html()`、`esc_attr()`、`esc_url()` を通して出力します。
- 英語のページでも使うテンプレートでは、タイトルに `$event['label']`、固定の文言に `$text` を使います。
- 予定の説明欄（`$event['description']`）を表示するには、テンプレートで出力します。既定のテンプレートは表示しません。

渡る変数の一覧は[仕様の「テンプレートの差し替え」](docs/specification.md#テンプレートの差し替え)に、既定のCSSを外す方法は[仕様の「カスタマイズ」](docs/specification.md#カスタマイズ)にあります。

## 予定の入力と更新

- タイトルは「設定 → Museum Calendar」の表のとおりに入力します。
- 本日の予定は、`開館日` か `休館日` の予定を開館状況として表示します。どちらもない日は、開館状況を表示しません。
- 説明欄にURLだけの行を入れると、予定の名前がそのURLへのリンクになります。
- 予定は約15分ごとに取り直します。すぐに反映するには「設定 → Museum Calendar」の「今すぐ更新」を押します。
- 取得に失敗している間は、前回取得した予定を最終取得の日時とともに表示し続けます。
- ページキャッシュを使っている場合、本日の予定が前日のまま残ることがあります。予定を置いたページのキャッシュ時間を短くしてください。

職員向けの詳しい登録ルールは[運用手順の「予定の登録」](docs/operations.md#予定の登録)にあります。
