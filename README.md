# Museum Calendar for WordPress

一般公開したGoogleカレンダーから予定を取得し、月間カレンダーと本日の予定をWordPressのページに表示するプラグインです。
APIキーやGoogleへのログインは不要です。

## ステージングと開発環境

ステージング: https://collaborative-macaw-b043ed.instawp.site

mainへのpushでチェックが通ると、最新のプラグインがステージングに配備されます。

開発環境はDocker（wp-env）で動きます。Docker、Node.js、npmを用意して、次を実行します。

```sh
npm ci
npm run setup
```

- 確認ページ: http://localhost:8888/?pagename=calendar-demo
- 管理画面: http://localhost:8888/wp-admin/ （開発専用ログイン: `admin` / `password`）
- 2回目以降の起動は `npm run dev`、停止は `npm run stop`

必要なバージョンとテストの実行方法は[開発の手引き](docs/development.md)、配備の仕組みは[運用手順](docs/operations.md)にあります。

## 必要なもの

- WordPress 7.1.4以上、PHP 8.5.12以上、MariaDB 10.11.18以上
- 一般公開したGoogleカレンダー

## 導入

1. プラグインのZIPを用意します。作り方は[開発の手引き](docs/development.md)にあります。
2. WordPressの「プラグイン → プラグインを追加 → プラグインのアップロード」でZIPをインストールし、有効化します。
3. Googleカレンダーで表示したいカレンダーの「設定と共有」を開き、「予定のアクセス権限」で「一般公開して誰でも利用できるようにする」をオンにして、「すべての予定の詳細を表示」を選びます。
4. 「カレンダーの統合」にある「このカレンダーの公開URL」をコピーします。
5. WordPressの「設定 → Museum Calendar」の「Googleカレンダーの公開URL」に貼り付け、「設定を保存」を押します。
6. 「今すぐ更新」を押し、最終成功日時が表示されることを確認します。

公開URLの扱い:

- 一般公開したカレンダーの予定は誰でも閲覧できます。掲載してよい予定だけを入れてください。
- 「iCal形式の公開URL」も登録できます。「iCal形式の非公開URL」は登録できません。
- 保存したURLは設定画面に表示されます。空欄にして保存すると接続を解除し、取得済みの予定を消去します。
- 0.7.0以前に登録したGoogleカレンダーのiCal形式のURLは、更新時に自動で公開URLへ切り替わります。カレンダーが一般公開されていない場合は、手順3で公開してください。

## ページへの表示

固定ページや投稿にショートコードを書きます。

| ショートコード | 表示内容 |
| --- | --- |
| `[museum_calendar]` | 当月の月間カレンダー。前月と翌月へ移動できます。 |
| `[museum_calendar month="2026-11"]` | 指定した月だけの月間カレンダー |
| `[museum_calendar_today]` | 本日の日付と当日の予定 |

- 表示するのは予定のタイトルと時間だけです。日時は日本時間です。
- 週の始まり、月と曜日の言語、本日の日付の表記は、WordPressの「設定 → 一般」に従います。日付形式を `n月j日(D)` にすると `11月16日(月)` と表示します。
- 月間カレンダーは1ページに1つだけ置けます。

## 予定の種類

予定のタイトルから種類を決めます。テーマは種類ごとに色を付け、英語のページは表の英語で表示します。

| カレンダーに登録したタイトル | 種類（`kind`） | 英語での表示 |
| --- | --- | --- |
| `OPEN` | `open` | `OPEN` |
| `CLOSE` | `closed` | `CLOSED` |
| `お茶室営業日` | `tea` | `Tea Room Open` |
| `ガイドツアー開催日` | `tour` | `Guided Tour` |
| `結婚式` | `wedding` | `Wedding` |
| `夜間特別開館` | `evening` | `Special Evening Opening` |
| `コンサート` | `concert` | `Concert` |
| `イベント` | `event` | `Event` |

- 表にないタイトルは種類が未定義（`other`）になり、テーマの色が付かず、英語のページでも登録したタイトルのまま表示します。「設定 → Museum Calendar」の「種類が未定義の予定名」で確認できます。
- 種類の追加にはプラグインの更新が必要です。新しいタイトルを使う前に開発の担当者に依頼してください。
- プラグインは種類ごとの色を付けません。色はテーマが `[data-kind="tour"]` のように指定します。

## 英語のページ

ショートコードに `lang="en"` を付けると、文言がすべて英語になります。サイトの言語を変える必要はありません。

```
[museum_calendar lang="en"]
[museum_calendar_today lang="en"]
```

- 予定のタイトルは、[予定の種類](#予定の種類)の表の英語に置き換えます。
- テーマでテンプレートを差し替えている場合は、[テンプレートの対応](docs/specification.md#テンプレートの差し替え)も必要です。

## 見た目の変更

色と寸法（CSS変数）、表示する予定（フィルター）、HTML（テンプレート）をテーマから変更できます。方法は[仕様の「カスタマイズ」](docs/specification.md#カスタマイズ)にあります。
プラグインのファイルは更新で上書きされるため、編集しないでください。

## Googleカレンダーでの予定の入力

登録したカレンダーの予定は、すべてサイトに表示します。サイトに載せる予定だけを入れる専用のカレンダーを使ってください。

- **タイトル**: [予定の種類](#予定の種類)の表のとおりに入力します。`Open` や `ＯＰＥＮ` は別のタイトルになり、種類が未定義になります。休館日は `CLOSED` ではなく `CLOSE` です。
- **時間**: 時刻を決めない予定は「終日」にチェックを入れます。サイトでも「終日」と表示します。
- **繰り返し**: 毎日の開館時間や毎週の休館日は、1日ずつ入力せず「繰り返さない」から繰り返しを設定します。カレンダーの予定が2,000件を超えると取得できなくなりますが、繰り返しは何回でも1件です。
- **臨時休館**: プラグインは開館と休館を判定しません。繰り返しの `OPEN` がある日は、その日の `OPEN` を「この予定」だけ削除してから `CLOSE` を作ります。
- **表示しない項目**: 説明、場所、ゲストはサイトに表示しません。

## 予定の更新

- 予定は約15分ごとに取り直します。すぐに反映するには「設定 → Museum Calendar」の「今すぐ更新」を押します。
- 取得に失敗すると、前回の予定を最長24時間表示します。それを過ぎると、予定を取得できない旨を表示します。
- ページキャッシュを使っている場合、本日の予定が前日のまま残ることがあります。予定を置いたページのキャッシュ時間を短くしてください。
