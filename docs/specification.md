# Museum Calendar for WordPressの仕様（1.0.0）

## 動作環境

WordPress 7.1.4以上、PHP 8.5.12以上、MariaDB 10.11.18以上。

## 接続と更新

- 管理者がGoogleカレンダー1つの「iCal形式の非公開URL」または「iCal形式の公開URL」を登録する。設定変更と手動更新には権限とnonceが必要。取得時はリダイレクトを追わない。
- 接続欄を空のまま保存すると現在の接続を維持し、入力が不正なら設定を変更しない。接続設定の保存に成功すると予定を取得する。接続先の変更（非公開URLのリセットを含む）と接続解除では、以前の予定を消す。
- 非公開URLの秘密の部分はDBの `museum_calendar_google_calendar_secret` とGoogleへの取得リクエストだけで扱う。URL、カレンダーID、秘密の部分を画面・ログ・エラーに出力しない。管理画面に表示するのは登録の有無と公開・非公開の別だけ。保存した秘密の部分が不正なら未登録として扱う。
- 表示時とWP-Cronで約15分ごとに更新する。同時取得を抑止し、失敗後の自動再試行は5分以上空ける。取得上限は2 MiB、2,000予定（VEVENT）。当月を展開できたデータだけを採用し、正常な空のカレンダーは予定の削除として反映する。
- 更新失敗時は、最後に取得できた予定を期限なく保持し、最終取得日時を添えて表示する。成功履歴がない場合や指定月を展開できない場合は、取得・表示できない旨を案内する。未設定時は接続が必要な旨だけを表示する。
- プラグインを無効化すると定期取得が止まり、設定と予定は残る。削除すると設定、取得済みの予定、定期取得の登録を消す。

## 表示

- `[museum_calendar]` は当月を表示する。月送りは翌々月まで。固定月の `[museum_calendar month="YYYY-MM"]` はこの制限を受けず、月送りを表示しない。
- `[museum_calendar_today]` は日本時間の本日の日付、開館状況、当日の予定を表示する。どちらのショートコードも英語表示には `lang="en"` を使う。週の始まりはWordPressの一般設定に従う。
- 日付と時間の基準は `Asia/Tokyo`。繰り返しとタイムゾーンの解釈にはsabre/vobjectを使う。複数日の予定は該当する各日に表示し、終日予定、開始時刻の順に並べる。
- 説明は書式を除いた500文字までのテキストとしてテーマに渡す。HTTPまたはHTTPSのURLだけを書いた最初の行は、説明から取り出して予定名のリンクに使う。既定のテンプレートでは説明本文を表示しない。参加者・主催者・場所・添付ファイルはテンプレートにも渡さない。

## 予定の種類

管理画面の「予定の種類と英語での表示」で、タイトルごとに種類、英訳、背景色を設定する。空欄の行に入力して保存すると追加、既存のタイトルを空にして保存すると削除になる。タイトルは前後の空白を除いて完全一致で照合する。未登録のタイトルは `other` とし、英訳がない予定は英語ページでも元のタイトルを使う。「種類が未定義の予定名」では当月から12か月分を確認できる。

同じ日に `closed` があれば、その日の `open` を月間・本日の両方から除く。本日の開館状況は `closed`、次に `open` の順で決める。どちらもない日は開館状況を出さない。判定は日単位で、時刻付きの `open` では開館時間も表示する。

## カスタマイズ

既定のテンプレートでは、予定の種類を `data-kind`、曜日を `data-weekday`（月曜が1）で指定して装飾できる。`monochrome.css` と `pop.css` は、既定テンプレートと美術館サイトの差し替えテンプレートで、月間カレンダーと本日の予定に各サンプルの配色を使う。美術館サイトでは日付を押して開く詳細にも同じ配色を使う。[サンプルCSS](../plugins/museum-calendar/samples/)

スタイルのハンドルは `museum-calendar`。テーマでショートコードを直接呼ぶ場合は `wp_enqueue_style('museum-calendar')` で読み込める。既定のCSSを外す場合は `wp_enqueue_scripts` で `wp_deregister_style('museum-calendar')` を呼ぶ。

### テンプレートの差し替え

テーマの `museum-calendar/` にある同名ファイルを子テーマ、親テーマの順に優先する。外側の `section` と前回取得時の案内はプラグインが出力する。テンプレートに渡る値は未エスケープ。[既定のテンプレート](../plugins/museum-calendar/templates/)

| 対象 | 渡る変数 |
| --- | --- |
| 共通 | `$lang`（`ja` または `en`）、`$text`（表示言語の固定文言） |
| `month.php` | `$month`（年月）、`$label`（見出し）、`$weekdays`（列順の曜日名）、`$weeks`（週ごとのセル）、`$empty`（予定のない月）、`$previous`・`$next`（`month`・`url`・`label`。移動できなければnull） |
| `today.php` | `$today`（DateTimeImmutable）、`$date`（表示用の日付）、`$weekday`（曜日名）、`$events`（開館・休館を含む予定）、`$status`（`kind`・`color`・`label`・`label_lang`・`hours`。開館状況がなければnull） |

月内のセルは `date`、`day`、`weekday`、`today`、`events` を持ち、月外のセルはnull。月間と本日の予定は同じキーを持つ。

| 予定のキー | 内容 |
| --- | --- |
| `title`、`label`、`label_lang` | 登録時のタイトル、表示用タイトル、その言語属性。英訳のないタイトルを英語ページに出すときだけ `label_lang` が `ja` になる |
| `kind`、`color` | 予定の種類、設定した背景色（未指定なら空文字） |
| `time`、`all_day`、`start`、`end` | 表示用の時間、終日かどうか、その日の開始・終了時刻 |
| `description`、`url` | 説明本文とリンク先。それぞれ未指定なら空文字 |
